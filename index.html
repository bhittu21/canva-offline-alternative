Run on Linux

Run Design Studio on macOS or Linux with VS Code

  1. Install Node.js LTS from nodejs.org, Git from git-scm.com and Visual Studio Code from code.visualstudio.com.
  2. Open VS Code, press Ctrl+Shift+P (Cmd+Shift+P on a Mac), choose Git: Clone and paste: 
    https://github.com/bhittu21/canva-offline-alternative
    Pick a folder and click Open when VS Code asks.
  3. Open the terminal with Terminal › New Terminal and run: 
    npm install
npm run dev
    The first run downloads what it needs once (a few hundred MB). After that, Design Studio opens and works offline.
  4. Next time, open the folder in VS Code and run npm run dev again. To update, run git pull and npm install first.

On some Linux systems (for example Ubuntu 24.04) the window may not open because of a security setting. Then start it with npx electron-vite dev -- --no-sandbox. We have tested these steps on Linux. On macOS the same steps should work, but we have not tested them on a Mac yet.

Questions

Is Design Studio really free?

Yes. No subscription, no trial and no watermark. If you connect a paid AI service with your own key, that service bills you directly.

Does it work without internet?

Yes. Templates, editing, fonts, icons, saving and downloading all work offline. Internet is only used for optional extras you turn on.

Do I need an account?

No. Install it and start designing.

Windows says “Windows protected your PC”. Is it safe?

The message appears because the installer is new and not code-signed yet. Click More info, then Run anyway. The installer is built from the public source code by GitHub's own servers.

Is there a macOS or Linux version?

A macOS app is coming. Today you can run Design Studio on macOS and Linux from its source code with VS Code. See the steps above.

Is this Canva?

No. Design Studio is an independent app inspired by easy design tools like Canva. It does not use Canva's code, templates, images or servers.

How do I get updates?

The download button always gives you the newest version. Install it over your current version; your designs are kept.
